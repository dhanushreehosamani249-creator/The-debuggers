💰 PennyWise AI — Smart Finance for Students

📌 About the Project

PennyWise AI is an AI-powered student finance management application designed to help students track their income and expenses, manage budgets, understand spending habits, predict upcoming expenses, and achieve their savings goals.

The application combines financial tracking, data analysis, and personalized recommendations to help students develop better financial habits.

🎯 Problem Statement

Students often struggle to manage limited allowances, scholarships, educational expenses, subscriptions, transportation costs, and personal spending. Without proper financial planning, saving money and controlling expenses can become difficult.

💡 Our Solution

PennyWise AI provides students with a simple and intelligent platform to monitor their finances, understand spending patterns, forecast expenses, and make better budgeting decisions.

✨ Key Features

1. Income and Expense Tracking — Record pocket money, scholarships, earnings, and daily expenses.
2. Smart Budget Management — Set monthly budgets and monitor spending by category.
3. AI-Powered Spending Insights — Identify spending patterns and receive personalized recommendations.
4. Expense Forecasting — Estimate total expenses by the end of the month.
5. Goal-Based Savings — Create savings goals for laptops, college trips, and other needs.
6. Financial Education — Learn about budgeting, saving, inflation, and compound interest.

🛠️ Technology Stack

- Frontend: React.js and Vite
- UI Styling: Tailwind CSS
- Backend: Python and FastAPI
- Database: PostgreSQL / Supabase
- Data Analysis and Machine Learning: Pandas and scikit-learn
- Charts: Recharts
- Version Control: Git and GitHub

Note: The technology stack may be updated to reflect the technologies actually implemented by the team.

🔄 How It Works

1. The student records income and expenses.
2. The application categorizes and summarizes transactions.
3. The dashboard displays balances, budgets, and spending charts.
4. The analysis module identifies spending patterns.
5. The forecasting module estimates upcoming expenses.
6. The recommendation engine suggests practical saving strategies.
7. The student tracks progress toward savings goals.

🤖 AI and Machine Learning

The application aims to use data analysis and forecasting to provide useful financial insights.

Planned intelligent features include:

- Expense categorization.
- Spending pattern analysis.
- End-of-month expense prediction.
- Unusual spending detection.
- Personalized savings recommendations.

Forecasts are estimates, not guaranteed outcomes. The final implementation will determine which AI and machine learning methods are used.
